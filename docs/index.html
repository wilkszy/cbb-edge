Best spread value

Biggest gaps between the book and the KenPom projection, in games with spreads of 20 or less. Huge spreads are left out because projections run consistently smaller than the book there.

Best moneyline value

Model win probability (KenPom blended 50/50 with the market) minus the market's no-vig probability. Shown when the edge is at least 3 points and the market gives the side a 15% to 85% chance.

Spread and moneyline agree

Games where both the spread gap (2+ pts) and the moneyline edge point to the same side.
